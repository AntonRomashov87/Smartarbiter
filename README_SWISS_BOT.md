# 🤖 Smart Арбітр Telegram Bot

Бот для автоматичного надсилання жеребкування учасникам турніру зі Smart Арбітра.

## 🎯 Особливості

✅ **Автоматичне відстеження** - моніторить Firebase кожну хвилину  
✅ **Миттєві сповіщення** - як тільки створено новий тур  
✅ **Проста реєстрація** - учні пишуть /start і автоматично реєструються  
✅ **Адмін панель** - зручне керування списком учнів  
✅ **БАЙ підтримка** - правильно обробляє вільні від гри

## 🚀 Швидкий старт

### 1. Створи бота

```
@BotFather
/newbot
Swiss Arbiter Pairings
swiss_arbiter_pairings_bot
```

Збережи токен!

### 2. Налаштуй змінні

Створи `.env` файл:

```env
# Telegram
TELEGRAM_TOKEN=твій_токен_від_botfather
ADMIN_ID=твій_telegram_id

# Firebase (з Smart Арбітра)
FIREBASE_DATABASE_URL=https://твій-проект.firebaseio.com
FIREBASE_SERVICE_ACCOUNT={"type":"service_account",...}

# Турнір
TOURNAMENT_ID=id_турніру
```

**Як знайти ADMIN_ID:**
- Напиши своєму боту `/start`
- Подивись лог — там буде "Твій ID: 123456789"

**Як знайти TOURNAMENT_ID:**
- Відкрий турнір у Smart Арбітрі
- URL виглядає: `https://swiss-chess.netlify.app/#tournament_2025_03_18_abc`
- ID = `tournament_2025_03_18_abc`

**Як отримати FIREBASE_SERVICE_ACCOUNT:**
1. Firebase Console → Project Settings
2. Service Accounts → Generate new private key
3. Скопіюй весь JSON як один рядок

### 3. Запусти локально (тест)

```bash
pip install -r requirements_swiss.txt
python swiss_arbiter_bot.py
```

### 4. Деплой на Render

1. Створи обліковий запис на [Render.com](https://render.com)
2. New Web Service
3. Завантаж файли:
   - `swiss_arbiter_bot.py`
   - `requirements_swiss.txt`
4. Start Command: `python swiss_arbiter_bot.py`
5. Додай Environment Variables (всі з .env)
6. Deploy!

## 📱 Інструкція для учнів

1. Знайди бота: `t.me/твій_бот_username`
2. Натисни `/start`
3. Бот автоматично розпізнає тебе по імені в Telegram
4. Якщо не розпізнав - напиши своє прізвище та ім'я
5. Готово! Тепер ти отримуватимеш сповіщення 🎉

## 👨‍🏫 Інструкція для тренера (адміна)

### Початкове налаштування

1. **Додай учнів** (кнопка ➕):
   - Іваненко Іван
   - Петренко Петро

   - Бот почне моніторинг

3. **Перевір список** (кнопка 📋):
   - Побачиш хто вже зареєструвався (✅)
   - Хто ще ні (⏳)

### Під час турніру

**Автоматично:**
- Бот моніторить Firebase кожну хвилину
- Коли створюєш новий тур → бот миттєво надсилає всім

**Вручну:**
- 🔍 Перевірити жеребкування — подивитись поточний тур
- ⚠️ Незареєстровані — нагадати учням

## 🐛 Troubleshooting

**Бот не надсилає сповіщення:**
- Перевір чи правильний `TOURNAMENT_ID`
- Перевір чи є учні в списку (📋 Список учнів)
- Перевір логи — бот пише що робить

**Учень не може зареєструватись:**
- Перевір чи додано його ім'я (➕ Додати учня)
- Ім'я має бути точно як у Smart Арбітрі
- Або учень може написати своє ім'я вручну

**Firebase помилки:**
- Перевір `FIREBASE_SERVICE_ACCOUNT` (має бути валідний JSON)
- Перевір `FIREBASE_DATABASE_URL`
- Перевір що service account має права читання

## 💾 Збереження даних

Бот зберігає дані в `data.json`:
- Список учнів
- Chat ID кожного
- Останній оброблений тур

При перезапуску всі дані залишаються!

## 🔒 Безпека

- Токен бота зберігай в змінних оточення
- Service account не коміть в Git
- ADMIN_ID тримай в секреті
